## Standing constraints — these are the user's, not negotiable

1. **Never push.** Commit freely; push is gated on the user explicitly. 32 commits are waiting
   behind that gate. This is verbatim: *"you can commit anything, only push becomes gated by me."*
2. **Never run the full suite more than once per task.** The user has objected to this twice, in
   capitals. Run the module that changed; the full suite runs once, by the implementer, at the end.
   A full run is 4m34s, and that is 4m34s of the user's waiting, not yours — the cost is their
   attention and it is paid up front. A second full run needs a reason you can state out loud;
   "to be sure" is not one.
3. **Never poll with `sleep`.** The harness notifies on completion. ~2 hours were lost to this.
   Related: never stop a run with `pkill -f "uv run pytest"` — the pattern matches the shell running
   the compound command that contains it, so it kills itself and your own session's commit, while the
   real target survives. Target by PID or use the harness's stop mechanism.
4. **No AI attribution in commit messages** — no `Co-Authored-By`, no "generated with". The user had
   to rewrite 11 signed commits to strip these before a public push.
5. **Commit signed** (`git commit -S`). If gpg fails, say so and ask for a re-prime — do not leave
   work staged silently.
6. **Cost is a live constraint.** The user flagged ~$350 spent. Prefer the cheap measurement over
   the broad re-run; hand over a precise diagnosis rather than grinding.

## Two traps this branch already fell into

- **A green suite can mean inert rather than correct.** 260 of 1,075 declared types had no shape
  targeting them, so both directions of the corpus went quiet: bad instances were not rejected *and*
  good instances passed without being checked. `scripts/diagnose_shape_coverage.py` exists as a
  committed gate for exactly this.
- **A figure measured on an unfixed path is not a figure.** "193 → 0 unresolved refs" was accepted
  once without asking how it was measured; the measurement ran on a path that double-prefixed
  cwd-relative paths, so 0 of 37 sibling documents had loaded. The real figure was 206 over 14 of 38.
  Ask how every number was produced.
